Rolling Dice Game

About

A simple interactive dice-rolling application that simulates rolling a dice and generates random results. This project was developed to practise programming fundamentals and front-end development.

Technologies Used

- HTML
- CSS
- JavaScript

Features

- Simulates dice rolling.
- Generates random dice results.
- Interactive user interface.
- Displays the outcome of each roll.

What I Learned

- JavaScript random number generation.
- DOM manipulation.
- Handling user interactions.
- Building interactive web applications.
